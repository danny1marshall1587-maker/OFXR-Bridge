# OFXR Bridge v0.2.13.1 (Adaptive Mod)

## Summary of Changes

This release is a community modification of OFXR Bridge v0.2.13.1 that introduces **Auto-Adaptive Frame Generation**:

### 1. Auto-Adaptive Frame Generation
* **Native 1X Mode (Bypass)**: If the system can achieve and maintain the target refresh rate natively (e.g. 90 FPS), frame generation is completely bypassed. This eliminates optical-flow latency and potential visual artifacts during high-performance scenes.
* **Auto 2X Activation**: When native frame rate dips below the target threshold (e.g. below 87 FPS on a 90 Hz headset) for 4 consecutive frames, 2X frame generation kicks in automatically, pacing the game to 45 FPS and synthesizing intermediate frames to maintain a smooth 90 Hz output.
* **Intelligent Headroom Recovery**: While in 2X mode, the layer tracks real application rendering work time ($t_{\text{render}}$). If rendering time consistently stays within the native frame budget (with at least 3 ms of headroom) for 3 continuous seconds, the bridge smoothly disengages back to Native 1X.
* **Anti-Thrashing / Hysteresis**: Protects against rapid mode flip-flopping when performance hovers near the boundary.

### Configuration (`ofxr/ofxr_bridge.ini`)
```ini
[adaptive]
adaptive_enabled=1
target_fps=90
drop_threshold_fps=87
drop_frame_count=4
recovery_headroom_ms=3
recovery_delay_ms=3000
allow_triple=0
```
